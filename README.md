# Tunnel Browser

Браузер, который открывает сайты **только через ваш VPN**. Пока VPN не подключён, у браузера
нет интернета вообще: ни одна страница не загрузится в обход, даже если сервер внезапно отвалится.

Остальные программы на компьютере работают как обычно, напрямую. Не нужно включать VPN на весь
компьютер и выключать его, чтобы зайти в банк или на Госуслуги: нужное открываете в Tunnel
Browser, всё остальное — в обычном браузере.

Работает на **Windows** и **macOS**. Нужна ссылка на сервер от вашего VPN-провайдера
(подходят ссылки для Xray: `vless://`, `vmess://`, `trojan://`, `ss://` или ссылка на подписку).

## Скачать

Последняя версия всегда здесь: **[страница загрузки](https://github.com/nlbeglov/tunnel-browser/releases/latest)**.
В разделе **Assets** выберите файл для своего компьютера:

| Компьютер | Файл |
|---|---|
| Windows | `TunnelBrowser-Setup-…-x64.exe` |
| Mac с чипом Apple (M1, M2, M3, M4 и новее) | `TunnelBrowser-…-arm64.dmg` |
| Mac с процессором Intel | `TunnelBrowser-…-x64.dmg` |

Какой у вас Mac: меню Apple () → «Об этом Mac». Если там написано «Чип Apple M…» — берите `arm64`,
если «Процессор Intel» — `x64`.

**ZIP-архивы скачивать не нужно.** `TunnelBrowser-…-arm64.zip` и `…-x64.zip` нужны Mac-версии для
автообновления, а «Source code (zip)» — это исходный код, а не программа. Файлов в списке много,
и GitHub показывает только первые: если установщика для Windows не видно, нажмите
**«Show all … assets»** под списком.

## Установка

### Windows

Запустите скачанный файл, приложение установится и откроется само.

Windows может показать окно «Windows защитил ваш компьютер»: у приложения пока нет платной
подписи разработчика. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

### macOS

1. Откройте скачанный `.dmg` и перетащите **Tunnel Browser** в папку **«Программы»**.
2. Запустите его из «Программ». macOS скажет, что не может проверить приложение: у него пока
   нет подписи Apple. Нажмите **«Готово»**.
3. Откройте **«Системные настройки» → «Конфиденциальность и безопасность»**, прокрутите вниз и
   напротив сообщения о Tunnel Browser нажмите **«Всё равно открыть»**, затем подтвердите.

Это нужно сделать один раз. Если вместо этого macOS пишет, что приложение «повреждено», выполните
в «Терминале» команду и запустите приложение снова:

```bash
xattr -dr com.apple.quarantine "/Applications/Tunnel Browser.app"
```

## Как начать

1. Скопируйте ссылку на сервер или на подписку из личного кабинета вашего VPN-провайдера.
2. В Tunnel Browser нажмите **«Добавить сервер»** (или на плашку «Не подключено» справа вверху):
   откроется вкладка «Настройки». Вставьте ссылку в поле «Добавить сервер или подписку» и нажмите
   **«Добавить»**. Можно вставить сразу несколько ссылок, по одной на строку. Подписка
   обновляется сама.
3. Выберите сервер и нажмите **«Подключить»**. Приложение запомнит его для этого окна.

Через пару секунд браузер откроется, а справа вверху появятся флаг страны и IP-адрес, под
которым вас видят сайты. Если сервер не отвечает, браузер останется заблокированным и покажет
причину.

## Что умеет

- **Несколько окон с разными серверами.** Каждое окно — отдельный профиль со своим названием и
  цветом, своим сервером и IP, своими куки, входами, закладками и часовым поясом. Сайты не
  видят, что это один человек. Профиль видно сразу: полоса вкладок окрашена в его цвет, слева —
  название и флаг страны сервера; на Windows флаг виден и на значке в панели задач, а в Alt+Tab —
  название. Новое окно или другой профиль: Ctrl/⌘+N или нажмите на название профиля.
- **Вкладки как в Chrome**, в заголовке окна рядом с кнопками окна. Их можно перетаскивать. По правой кнопке можно дублировать вкладку,
  закрыть другие или добавить её в закладки. Случайно закрытую вкладку возвращает Ctrl/⌘+Shift+T.
- **Закладки.** Звёздочка ☆ в адресной строке добавляет страницу. Под адресной строкой есть
  панель закладок, на стартовой странице — плитки. Кнопка «Закладки» справа вверху открывает
  список с поиском. Порядок меняется перетаскиванием.
- **Вкладки не теряются.** После перезапуска открываются те же вкладки, но загружаются только
  когда подключится VPN.
- **Серверы и подписки.** Можно держать несколько серверов и подписок. Каждое окно помнит свой
  сервер, даже если провайдер переименовывает серверы в подписке (например, пишет в названии
  остаток трафика). Сменить сервер можно только явно, и приложение переспросит: у другого
  сервера другой IP. У подписки видно, сколько трафика израсходовано и до какого числа она
  действует.
- **Пинг** виден на стартовой странице и в настройках: время ответа сайта через VPN. Он
  обновляется раз в 10 секунд, при каждой проверке, что сервер жив; кнопка ⟳ рядом измеряет
  его сразу.
- **Время для сайтов.** На новой вкладке рядом с часовым поясом идут часы: столько времени
  сейчас видят сайты.
- **Меню ⋮** справа вверху, как в Chrome: открывается влево под кнопкой. В нём новая вкладка,
  новое окно (с выбором профиля) и настройки.
- **Настройки как в Chrome:** отдельная вкладка «Настройки» с разделами слева и поиском сверху
  (⋮ → «Настройки»). Отметка «только «Профиль»» означает, что настройка касается только этого
  окна.
- **Обновления в одну кнопку.** Когда выходит новая версия, сверху появляется
  «Доступна новая версия» с кнопкой **«Обновить»**. Приложение скачает её, установит и
  перезапустится. Что изменилось, видно по ссылке «Что нового» и в настройках (⋮ → «Настройки» → «О Tunnel Browser»).

### Горячие клавиши

На Windows — Ctrl, на Mac — ⌘ (Cmd).

| Действие | Клавиши |
|---|---|
| Новая вкладка / закрыть вкладку | Ctrl/⌘+T / Ctrl/⌘+W |
| Окна и профили: открыть, создать | Ctrl/⌘+N |
| Закрыть окно | Ctrl/⌘+Shift+W |
| Вернуть закрытую вкладку | Ctrl/⌘+Shift+T |
| Следующая / предыдущая вкладка | Ctrl+Tab / Ctrl+Shift+Tab |
| Перейти в адресную строку | Ctrl/⌘+L |
| Обновить страницу | Ctrl/⌘+R |
| Назад / вперёд | Alt+← / Alt+→ (Mac: ⌘+[ / ⌘+]) |
| Добавить в закладки | Ctrl/⌘+D |
| Показать или скрыть панель закладок | Ctrl/⌘+Shift+B |
| Все закладки | Ctrl/⌘+Alt+B |
| Масштаб страницы | Ctrl/⌘ + «+», «−», «0» |

Открыть закладку или ссылку в новой вкладке — клик с Ctrl/⌘ или средней кнопкой мыши.

## Насколько это надёжно

- **Нет VPN — нет сети.** Браузер настроен так, что у него есть единственный путь в интернет —
  через ваш сервер. Это не «проверка, включён ли VPN», а отсутствие другого пути. Если сервер
  перестал отвечать, страницы просто перестанут грузиться, напрямую ничего не уйдёт.
- **Если что-то сломалось — блокировка.** Если ядро VPN неожиданно завершилось, браузер сразу
  блокируется и пишет, что случилось. Если сервер перестал отвечать, через несколько секунд
  вкладки скрываются, а справа вверху появляется «Туннель недоступен». Когда сервер снова
  ответит, вкладки вернутся сами.
- **Нет утечки DNS.** Адреса сайтов узнаёт VPN-сервер, а не ваш интернет-провайдер: браузер
  не делает DNS-запросов с этого компьютера.
- **Сайты не видят, что вы из другой страны.** Часовой пояс в браузере — как в стране
  VPN-сервера (в больших странах — как в регионе сервера), язык и форматы дат — английский
  (США), одинаковые для всех. Время на часах сайтов будет местным временем страны сервера.
  Страница, для которой это ещё не включилось, ничего не может отправить.
- **Смена IP не выдаст вас.** Если после подключения у вас другой IP-адрес, чем в прошлый раз,
  приложение до открытия сайтов спросит, очистить ли куки и входы: иначе сайты, где вы вошли,
  связали бы новый IP со старым. Если адрес тот же, вопроса не будет.
- **Ваш реальный IP не утечёт через WebRTC** (звонки и видео в браузере).
- **Сайты не видят ваше местоположение, камеру и микрофон**: эти разрешения запрещены.
- **Сайты не доберутся до вашей домашней сети**: из браузера недоступны роутер, принтеры и
  другие устройства локальной сети.
- **Для сайтов это обычный Chrome**: по браузеру не видно, что вы пользуетесь этим приложением.

Эти свойства проверяются тестами на настоящем VPN-подключении.

**Чего приложение не делает:** не защищает другие программы на компьютере — они работают
напрямую, как и задумано. И не скрывает от вашего интернет-провайдера сам факт, что вы
подключаетесь к VPN-серверу.

**Что зависит не от браузера.** Сайт может заподозрить VPN и по признакам самого сервера: IP из
диапазона дата-центра, задержки, «отпечаток» сетевого стека сервера. Это решает выбор
провайдера и сервера. Текст, который вы набираете, сайт видит как есть: если печатать по-русски,
он увидит русские буквы.

## Ваши данные

- Серверы, закладки и открытые вкладки хранятся **только на вашем компьютере**, в зашифрованном
  виде: ключ хранит сама система (Windows или связка ключей macOS).
- Приложение не собирает статистику и никуда не отправляет ваши данные.
- **Напрямую, не через VPN**, приложение обращается только:
  - к адресу вашей подписки, чтобы обновлять список серверов;
  - к GitHub, чтобы проверять и скачивать обновления.
- Чтобы убедиться, что VPN действительно работает, приложение через VPN открывает служебные
  адреса Google и Cloudflare и узнаёт ваш IP выхода и его страну (по ней выбирается часовой
  пояс для сайтов). Если Cloudflare не ответил, IP узнаётся у ifconfig.co или ipinfo.io, тоже
  через VPN.
- Куки, кэш и входы на сайты можно стереть: ⋮ → «Настройки» → «Конфиденциальность и защита» →
  «Данные сайтов». Стираются данные только этого окна.

## Частые вопросы

**Браузер пишет «Браузер заблокирован».** VPN не подключён. Нажмите «Подключить» или выберите
другой сервер.

**При подключении пишет «сервер не отвечает».** Сервер недоступен или ссылка устарела.
Попробуйте другой сервер или обновите подписку (⋮ → «Настройки» → «Подключение», ⟳ у подписки). Если не
помогает, напишите своему VPN-провайдеру.

**Вместо IP написано «IP не определён».** VPN работает, но ни один сервис, по которым
приложение узнаёт IP, не ответил через этот сервер. Что именно они ответили, видно в
«Настройки» → «Подключение». Часовой пояс для сайтов в этом случае — UTC.

**Пишет «Сервера … больше нет».** Провайдер убрал сервер этого окна из подписки. Приложение не
выбирает другой сервер само: нажмите «Выбрать сервер» и укажите новый.

**Вкладки пропали, справа вверху «Туннель недоступен», сверху жёлтая полоса.** Сервер перестал
отвечать во время работы. Трафик напрямую не идёт, поэтому вкладки скрыты, пока связь не
восстановится. Когда сервер снова ответит, они вернутся сами; можно не ждать и нажать
«Переподключить» или сменить сервер.

**Ссылка не добавляется.** Приложение сообщит причину. Чаще всего это одно из трёх:
- ссылка требует отключить проверку сертификата сервера (`allowInsecure`);
- ссылка на сервер без шифрования;
- протокол пока не поддерживается (Hysteria2, TUIC, WireGuard).

Первые два варианта небезопасны и намеренно не принимаются. Попросите у провайдера обычную
ссылку VLESS (Reality или TLS), VMess, Trojan или Shadowsocks.

**Mac после обновления спрашивает доступ к «Tunnel Browser Safe Storage».** Нажмите
**«Разрешить всегда»** и введите пароль от Mac. Это ключ, которым зашифрованы ваши серверы и
закладки. macOS спрашивает о нём после каждого обновления, пока у приложения нет подписи Apple.
Если случайно нажали «Запретить», ничего не потеряно: перезапустите приложение и разрешите доступ.

**На Mac не устанавливается обновление.** Приложение должно лежать в папке «Программы»: при
запуске из «Загрузок» или прямо из `.dmg` оно не может заменить само себя. При первом запуске
оно предложит переместиться туда само.

**Сайты открываются на английском.** Так задумано: язык браузера одинаковый для всех, чтобы
сайт не увидел русский язык при IP другой страны. Язык конкретного сайта можно выбрать в его
настройках.

**Не приходят уведомления от сайтов, не работает офлайн-режим.** Service worker’ы, на которых
это держится, отключены: они работают после закрытия страницы, и на них нельзя надёжно
подменить часовой пояс.

**Вместо значка сайта — буква.** Значки загружаются только через VPN того окна, где открыт сайт.
Пока VPN не подключён или у сайта нет значка, показывается первая буква.

**Как удалить профиль.** Закройте его окно, нажмите Ctrl/⌘+N (откроется «Настройки» → «Окна и
профили»), у профиля — значок карандаша → «Удалить профиль». Его куки, входы, закладки и вкладки удалятся, серверы останутся.
